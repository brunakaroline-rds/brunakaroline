# Como Adicionar a Imagem ao Portfólio

## Passo a Passo

1. Localize a imagem no seu computador
2. Renomeie para: `bruna-hero.jpg`
3. Copie para: `D:\TUDO\Codes\Bruna\assets\images\hero\`
4. Atualize o navegador (F5)

Ou use este comando no terminal:

```powershell
# Substitua "caminho-da-imagem.jpg" pelo caminho real
Copy-Item "C:\Users\luisf\Downloads\sua-foto.jpg" -Destination "assets\images\hero\bruna-hero.jpg"
```

A imagem será exibida automaticamente no hero section!
