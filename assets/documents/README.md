# Documentos

## Currículo (CV)

Adicione o currículo em formato PDF nesta pasta:

**Nome do arquivo:** `cv.pdf`

### Especificações
- **Formato:** PDF
- **Tamanho máximo:** 2MB
- **Conteúdo:** Currículo completo e atualizado

### Nota
O arquivo `cv.pdf` abre no botão "Ver Currículo" do topo da página (visualizador com opção de baixar)
e nos links "Baixar Currículo (PDF)" do rodapé. Para atualizar o currículo, substitua o arquivo mantendo o nome.

Qualquer link para um PDF com o atributo `data-document` abre no mesmo visualizador.
O currículo fica público: não inclua CPF, endereço ou outros dados que não devam ser divulgados.

Certifique-se de que o arquivo está otimizado e com tamanho reduzido para download rápido.

## TCC

**Nome do arquivo:** `tcc.pdf`

Abre no botão "Ler o TCC" do card de pesquisa, na seção Formação, e é baixado pelo link "Baixar PDF"
ao lado. Use a versão sem o termo de autoria assinado. Para atualizar, substitua o arquivo mantendo o nome.
